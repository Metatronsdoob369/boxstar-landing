Why This Exists

AI generates code.
Nobody governs it.

Thesis

Every AI coding tool gives you output. None of them give you standards. BOXSTAR ships governance files — Laws — that any agent reads on ingestion. The agent doesn't get smarter. It gets disciplined. It maps failure first, then avoids it. Every session compounds. Every repo that carries the Laws propagates the behavior.

PRINCIPLE 01

Contract-First

Governance .md files define what the agent can and cannot do. No fine-tuning. No API keys. Drop files into a repo and the behavioral delta is immediate.

PRINCIPLE 02

Failure-First Convergence

The system maps every way to fail before attempting to succeed. Over time, the decision space narrows until the only remaining moves are correct ones.

PRINCIPLE 03

Passive Propagation

When an agent reads your Laws, it behaves differently. When it collaborates with another agent, the behavior transfers. Distribution disguised as documentation.
